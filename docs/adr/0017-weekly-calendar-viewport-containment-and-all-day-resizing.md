# ADR 0017: 周历指挥台视口自适应锁定、全天栏动态缩放与跨模块交互规范

## 状态

已采纳 (Accepted)

## 上下文 (Context)

在个人工作台（Personal-Workbench）方案 A 的周历落地过程中，出现了一系列复杂的视图布局与跨模块交互挑战：

1. **视口滚动溢出**：若采用硬编码像素推算（如 `calc(100vh - 120px)`），在顶栏高度、外边距或分辨率微调时，容易导致外层浏览器窗口出现双滚动条。
2. **全天栏内容容量矛盾**：全天事项可能随秋招、考试或重要事件累积变多，固定高度装不下，过高又挤压下方 24 小时时间轴。
3. **滚轮事件冲突**：年份横向滚动条在鼠标滚轮滚动时，现代浏览器默认的 passive 监听器会导致垂直页面也跟随滚动。
4. **左右键行为混淆**：若所有点击都弹同一个排期弹窗，用户无法快速查看岗位的详细应聘轮次与状态。
5. **跨模块跳转断层**：从周历事项跳转至目标业务模块（如秋招模块 `/campus`）时缺乏上下文与自动展开。

## 决策 (Decision)

### 1. 严格纯 Flex 响应式视口自适应（0px 浏览器窗口滚动）

- 页面外层容器声明为 `h-[calc(100vh-92px)] min-h-0 overflow-hidden flex flex-col`；
- 顶部控制条、星期表头固定为 `shrink-0`；
- 24 小时时间轴网格声明为 `flex-1 min-h-0 overflow-y-auto`；
- **无论上方全天栏或顶栏如何增减高度，时间轴均毫秒级弹性占满剩余视口，外层页面绝对不出现任何纵向滚动条**。

### 2. 全天栏高度自由拖拽调节（Splitter Resizer Bar）

- 全天栏底部与时间轴之间内嵌拖拽调节分割条（`Splitter Resizer Bar`）；
- 支持鼠标在 `44px` 到 `260px` 之间自由平滑拖拽调整高度；
- 支持双击一键在默认高度（`64px`）与扩展高度（`130px`）之间切换；
- 高度偏好自动持久化到 `localStorage`；各日单元格内部支持独立滚动。

### 3. 操作行为明确分流

- **【左键单击 (Left Click)】**：打开 **事项详情弹窗 (ItemDetailModal)**，完整展示来源模块、排期信息、死线及秋招联动面板；
- **【右键单击 (Right Click)】**：拦截浏览器默认菜单，打开 **专属排期弹窗 (ScheduleModal)**，直接修改全天/定时排期或退回未排程；
- **超长标题横向平滑跑马灯（ScrollableTitle）**：鼠标悬停溢出标题时自动平滑滚动显示全名。

### 4. 原生非被动滚轮监听（Non-Passive Wheel Listener）

- 年份快速切换栏使用 `addEventListener('wheel', handleWheel, { passive: false })`；
- 显式执行 `e.preventDefault()` 与 `e.stopPropagation()`，保证鼠标滚轮在年份栏滚动时仅横向滑动年份胶囊，外部页面绝对保持静止。

### 5. 跨模块一键直达与自动展开（Deep Linking & Auto Expand）

- 跳转链接携带标识：`/campus?targetItemId=${item.id}`；
- 秋招页面根据 `targetItemId` 匹配 `deadlineItemId` 或 `rounds.itemId`，自动切换至表格模式、原地展开该企业全部面试轮次与流程步进器，并平滑居中滚动至该行。

## 效果与收益 (Consequences)

- 周历界面在任何分辨率屏幕下均能严丝合缝填满屏幕，消除外层滚动；
- 全天事项与定时日程兼顾视觉舒展与容量自定义；
- 周历、今日工作台与秋招模块实现了深度的双向联动闭环。
