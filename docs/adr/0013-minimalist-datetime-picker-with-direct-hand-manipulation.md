# 0013. 极简现代双指针模拟钟表与时分一体化日历组件架构

日期：2026-08-18  
状态：已接受

## 背景

在个人工作台的日常运转中，时间维度包含两种明确的场景诉求：

1. **纯日期排程**：如工作台日常排程（`/api/workbench/items/:id/schedule`）和秋招投递截止日，只需精确到「天」（`YYYY-MM-DD`）；
2. **分钟级精确安排**：如秋招面试轮次时间（`scheduledAt`）与事项具体死线（DDL），需要精确到「分」（`YYYY-MM-DD HH:mm`）。

此前存在以下交互痛点与体验缺陷：

- 遗留的原生控件（如 `<input type="datetime-local">`）视觉风格割裂且缺乏键盘掩码与钟表联动；
- 传统模拟钟表设计繁复密集（12 个数字与 60 刻度密布），且存在「指针切换与拖拽冲突」——想切换选中的指针时，因点击表盘导致时间意外发生跳变；
- 输入或格式错误时缺乏即时、直观的视觉警示（如边框标红）。

## 决策

1. **直接抓取拖动（Direct-Grab）双指针 SVG 模拟钟表**：
   - 为**时针（粗短）**与**分针（细长）**分别构建独立的加大透明抓取热区（`strokeWidth: 20`）；
   - **一步直达**：按住任意指针即可直接拖拽旋转，彻底消灭「先选中再拖动」的繁琐流程与误触跳变；
   - **表盘智能分区**：在表盘空白处按下时，内圈（$r \le 42$）自动识别为抓取时针，外圈（$r > 42$）自动识别为抓取分针；
   - **现代极简表盘**：去繁从简，仅保留 `12`、`3`、`6`、`9` 四大核心锚点与 8 个极简微点。

2. **输入焦点与指针变色实时联动**：
   - 键盘输入或光标聚焦在小时段（`HH`）时，时针亮起主题色（Accent）并伴随微光提示；
   - 键盘输入或光标聚焦在分钟段（`mm`）时，分针亮起主题色；
   - 时分数字选中态摒弃沉重刺眼的实色大底块，改用微透浅色底（`bg-accent-soft`）+ 主题色字（`text-accent`）+ 细致轮廓光（`ring-1 ring-accent/30`）。

3. **时分自动感知与 12h / 24h 智能解析**：
   - **无需手动开关**：检测到时分输入或表盘拖拽时自动激活时间；点击「仅保留日期」或仅输入年月日时自动回退为纯日期；
   - **国际化 AM / PM 胶囊**：采用紧凑的 `AM` / `PM` 按钮替代中文；
   - **双制式键盘输入**：支持 `14:30`（24 小时制）与 `02:30 pm`（自动大写转换并在入库前转换为标准 24 小时制）。

4. **即时格式与输入错误标红提示**：
   - 当遇到输入不完整、年份/月份/天数越界、时分超出合法范围时，输入框即时呈现红色警戒边框与柔和光晕（`border-critical ring-2 ring-critical/20`），并附带精准的文字提示微标。

5. **全项目统一契约与 `showTime` 场景化约束**：
   - `showTime={false}`（纯日期场景）：如工作台排程、秋招投递截止日，组件自动隐藏时钟与时分输入，面板收敛为精致紧凑的单列纯日历（`w-72`）；
   - `showTime={true}`（时分精确场景）：如秋招面试轮次安排、任务死线，展开日历与极简钟表双栏面板。

## 后果

- 全项目彻底淘汰原生 `datetime-local` 控件，所有日期与时间交互均收敛至一致、优雅且无障碍的 `DatePicker` 组件；
- 用户在选择日期与分钟级时刻时获得极简直观、防误触且反馈精准的现代输入体验。
