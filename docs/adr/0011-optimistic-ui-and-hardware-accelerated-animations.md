# 0011. 乐观缓存同步消除竞态闪现与 GPU 硬件加速动效架构

日期：2026-08-18  
状态：已接受

## 背景

在前端实现平滑的待办完成/删除滑出动效与数字过渡时，遇到了两个影响体验的关键问题：

1. **动画卡顿与掉帧**：执行度数字的缓动插值（`requestAnimationFrame`）运行在页面顶层，每秒 60 次全量 VDOM Diffing 阻塞了主线程，干扰 CSS 动画；
2. **离场后瞬间闪现回跳**：离场动画结束清除动效 Class 后，由于网络异步请求（GET `/api/todo/today`）在传输途中，本地 React Query 旧缓存项在几十毫秒延迟内以默认样式重新挂载到视图上，产生闪现。

此外，列表容器与横幅（如逾期警告横幅、已完成分组、全部完成卡片）在数量从 0 到 1 与 1 到 0（清空）时缺乏过渡动画，导致视觉跳跃。

## 决策

1. **GPU 硬件加速时序关键帧动效**：
   - 弃用基于多段 `setTimeout` 切换 Class 的重排式（Reflow）动画；
   - 在 `packages/web/src/index.css` 中引入纯 CSS GPU 关键帧 `@keyframes taskCompleteGlideOut`：
     - `0% - 20%`：打勾高亮反馈与原位停留确认；
     - `20% - 65%`：使用 `translate3d(115%, 0, 0)` 将图层交付 GPU 独立合成器向右滑出；
     - `65% - 100%`：在屏幕外平滑收起高度与边距至 0；
   - 标注 `will-change: transform, opacity, max-height`。

2. **状态隔离消灭全局重绘**：
   - 将 `useAnimatedValue` 缓动循环严格封装进独立的 `TodayExecutionCard`；
   - 数字与环形进度条动画期间，仅该卡片局部重绘，任务列表与页面其余部分零负担。

3. **React Query 乐观同步更新消除闪现**：
   - 在动画结束清除动效 Class 的**同一宏任务 tick 中**，通过 `queryClient.setQueryData` **瞬时乐观更新本地缓存**（完成项同步移入 `completed`，删除项同步从列表中移除）；
   - 本地缓存数据源与动画结束严格无缝衔接，从根源上消灭 0ms 闪现窗口。

4. **全场景 0 ↔ 1 容器生命周期动效**：
   - 容器出现（0 → 1）：挂载 `animate-expand-in` 自上而下平滑展开；
   - 容器清空（1 → 0）：挂载 `animate-collapse-out` 在 400ms 内折叠高度并淡出后卸载；
   - 新增待办：挂载 `animate-item-enter` 轻盈滑入。

## 后果

- 用户在完成、取消、软删除、恢复待办及面对逾期/已完成列表时，拥有极致丝滑、高帧率且零闪烁的流畅交互体验。
